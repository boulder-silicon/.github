# Boulder Silicon

**Student ASIC tapeouts at the University of Colorado Boulder!**

We design small digital chips as a team, verify them, and send them to be fabricated on the [Tiny Tapeout](https://tinytapeout.com) open-source shuttle. Then we get back a real chip for us to further test before use. Verification is very heavily emphasized.

## Join & Learn

All ASIC experience levels are welcome! Please sign up for a free [Cadence ASK](https://registration.cadence.com/CadenceApplicationLoginScreen?appcode=cos&langcode=en) account to learn more about ASICs. We highly recommend:

1. Semiconductor 101
2. Digital IC Fundamentals
3. Cadence RTL-to-GDSII Flow
4. Basic Static Timing Analysis
5. Design for Test Fundamentals
6. Verilog Language and Application
7. VHDL Language and Application
8. SystemVerilog for Design & Verification
9. C++ Language Fundamentals for Design and Verification

We also will be rolling out a free interactive reference guide on GitHub pages soon.
